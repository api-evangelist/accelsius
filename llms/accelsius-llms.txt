# Accelsius

> builds NeuCool, a two-phase, direct-to-chip liquid-cooling platform for AI, HPC and mission-critical
> data centers: a non-conductive dielectric refrigerant is pumped through cold plates mounted on
> CPUs and GPUs and removes heat by evaporation, so no water enters the IT rack. It supports 4,500W+

## How to consume it without getting blocked

accelsius.com runs the **MalCare WordPress firewall**. During this profiling pass it began answering
HTTP 403 with an HTML interstitial ("Blocked because of Malicious Activities") after a short burst of
item-level requests, and the block persisted while collection reads kept working. There is no
rate-limit header to read — enforcement without signalling.

- Honor `Crawl-delay: 10` from /robots.txt. One request per 10 seconds.
- Always pass `_fields`. A default post object is ~17KB because of `yoast_head` and `acf`.
- Use `_embed=true` to resolve author/terms/featured image in one round trip instead of three.
- Cache for 600 seconds — that is the `Cache-Control: max-age=600` the edge returns.
- Branch on content-type. A 403 here is HTML, not the JSON `{code, message, data.status}` envelope.
- Do not enumerate `/wp/v2/users`. It answers anonymously with 14 author records; API Evangelist
  models no operation, tool or skill against it.
